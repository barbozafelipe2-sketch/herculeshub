# Hercules Hub — App Store commercial channel

Commercial is native iOS with StoreKit 2. The separate test repository remains a free Netlify web/PWA.

## Implemented

- SwiftUI iPhone/iPad application target generated by XcodeGen.
- Sign in with Apple challenge/session client, without beta device identity.
- Verified StoreKit purchase, pending/cancelled handling, transaction updates, restoration and subscription management.
- Account-bound entitlement gating; expired/revoked/unknown purchases do not unlock weeks.
- All four weeks readable/exportable; free/current week usable; payment opens the remaining weeks.
- Safety holds override paid training access.
- Account deletion, PDF export and gated week/check-in clients.
- Versioned beta engine/assets and a tested commercial cycle adapter requiring explicit consent.
- Linux engine verification and macOS Swift tests/simulator build workflow.

## Outstanding

The HTTPS commercial backend is a documented contract, not implemented/deployed here. Configure account/plan/persistence, Apple server verification/notifications, deletion/report endpoints and App Store Connect/signing. Full native onboarding, meal replacement/photo flows, notifications, post-workout content and next-month approval UI need implementation and end-to-end tests.

Missing backend disables sign-in; incomplete purchase configuration prevents purchases. There is no fake account, paid bypass or fallback to beta endpoints.
